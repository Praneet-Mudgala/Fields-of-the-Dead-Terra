# Fields of the Dead
Fields of the Dead is my submission for Terra Week 3 made on Godot Engine. It is a fast paced survival game where a child on Halloween night steps into a strange portal into the Fields of the Dead, where he is attacked by evil spectres and pyres and needs to defend himself with his wand or risk becoming a ghost himself...

I built this game in Godot 4 using GDScipt!

## How to play
* Press this link made on Github Pages: https://praneet-mudgala.github.io/Fields-of-the-Dead-Terra/
* Press space to advance the story
* Use WASD or Arrow Keys to move
* Aim with your mouse
* Click or press space to shoot
* Survive for as long as possible!
* Have fun!

## More info
The main features of this game are:
* The automated wave spawner that spawns spectres and pyres from random places out of the camera before walking in
* Enemies that can calculate normalized global position vectors to move towards the player smoothly
* The aimable wand that tracks your mouse's position and fires projectiles to defend yourself
* The lasting high score system that saves your best run locally so that you can try and beat it
* Custom pixel art that I made myself for this game

I was inspired to build this game by the game Brotato, which is a roguelike wave spawning survival game. I wanted to add buffs like in Brotato, but I didn't have the skill to code it, so I built this instead.

## Running the source code locally
If you want to explore the project files or modify the game:
1. Clone or download this repo to your computer
2. Open Godot Engine 4.5.1
3. Import the 'project.godot' file
4. Press f5 to run the game locally or explore the code.
